Cline представили Desktop версию , отдельное приложение для macOS и Windows. Можно запускать несколько сессий, импортировать чаты из Claude Code и Codex и выбирать модель независимо от редактора.
По набору возможностей всё привычно для десктопного кодинг‑агента: параллельные сессии, выбор моделей, задачи по расписанию, без особых отличий от других клиентов.
Один из поводов попробовать: бесплатный пул моделей , доступный с аккаунтом Cline, хотя состав моделей меняется, а использование ограничено промо‑квотой.
Также есть ClinePass за $9,99 в месяц с лимитами на 5 часов, неделю и месяц; среди моделей GLM-5.3, Kimi K3 и Qwen3.8-Max. Либо подключаешь свой API‑ключ и платишь по тарифу провайдера.
Под капотом у Cline Desktop Tauri, а сам проект опенсорсный, код доступен на GitHub .
