Gopass — это бесплатный менеджер паролей с открытым исходным кодом, который хранит учетные данные в зашифрованном хранилище и запускается из командной строки. Его сопровождающие создали его как замену pass, стандартного менеджера паролей Unix. По умолчанию Gopass шифрует каждый секрет с помощью GPG и сохраняет хранилище в репозитории git. По умолчанию Gopass шифрует каждый секрет с помощью GPG и сохраняет хранилище в репозитории git. Git дает команде возможность фиксировать каждое изменение и позволяет синхронизировать одно хранилище между ноутбуками и серверами. Пользователи, которым нужны другие инструменты, могут переключить шифрование на возраст, переключить хранилище на ископаемый или отказаться от управления версиями с помощью флага --storage=fs.
Инструменту не требуется сетевое подключение, если оно не требуется пользователю, поэтому он также работает на изолированном компьютере, где компьютер не подключен к любой сети.
Закрытые ключи никогда не покидают вашу машину. Шифрование исходит от GnuPG, поэтому безопасность хранилища зависит от того, как каждый пользователь обращается со своим ключом GPG.
Сопровождающие указывают пользователям Homebrew, MacPorts, Fedora, Arch Linux, Alpine Linux, WinGet, Chocolatey, Scoop, а также порты FreeBSD и OpenBSD. Пользователям Fedora может сначала потребоваться включить репозиторий daftaupe/gopass Copr.
