Postman объявила о широкой доступности Passport от Postman, ознаменовав расширение компании в области безопасности API с помощью отдельного продукта, который дает организациям безопасный способ использования API, поскольку человеческие и нечеловеческие идентификаторы все чаще работают бок о бок. Новый продукт сохраняет реальные учетные данные API внутри сред клиентов, предоставляя командам безопасности полную атрибуцию каждого вызова, детальный контроль над доступом и возможность отозвать доступ за считанные секунды. Новый продукт сохраняет реальные учетные данные API внутри сред клиентов, предоставляя командам безопасности полную атрибуцию каждого вызова, детальный контроль над доступом и возможность отозвать доступ за считанные секунды.
Разработчикам и агентам ИИ необходимо постоянно вызывать API, но учетные данные, аутентифицирующие эти вызовы, ключи API, токены и секреты, исторически являются сложной задачей для контроля. Как только настоящие учетные данные попадают на компьютер разработчика, они могут быстро распространиться по файлам .env, репозиториям, инструментам чата, конфигурациям IDE и журналам CI, что затрудняет полный аудит или управление группами безопасности.
Один-единственный утекший учетный данные можно использовать тысячи раз, прежде чем проблема безопасности будет обнаружена и решена, а поскольку агенты ИИ начинают вызывать API в 1000 раз быстрее, чем люди, поверхность атаки расширяется быстрее, чем когда-либо прежде.
«Агенты ИИ получают свои возможности через API, что делает безопасный доступ к этим API более важным, чем когда-либо», — сказал Абхинав Астана, генеральный директор Postman. "Поскольку разработчики и агенты ИИ умножают количество выполняемых вызовов API, количество учетных данных в обращении растет так же быстро. Passport обеспечивает секретный подход к доступу к API, позволяя любому человеку или нечеловеческому лицу вызывать утвержденные API, даже не обладая реальными учетными данными".
Passport обеспечивает секретный доступ к платформам SaaS и позволяет разработчикам, машинам и агентам искусственного интеллекта обнаруживать и вызывать утвержденные API через управляемые, проверяемые удостоверения, даже не касаясь реальных учетных данных. В отличие от традиционных подходов к управлению ключами API и шлюзов, которые ориентированы на распространение и защиту секретов, Passport хранит учетные данные самостоятельно внутри сред клиентов.
