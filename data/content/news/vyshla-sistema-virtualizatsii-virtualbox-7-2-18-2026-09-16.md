15 сентября 2026 года состоялся выпуск обновления открытого, бесплатного и кроссплатформенного программного обеспечения для виртуализации для систем GNU/Linux, Solaris, macOS и Windows — проекта Oracle VirtualBox 7.2.18 . Предыдущая стабильная версия этого решения вышла в августе 2026 года.
В версии 7.2.18 разработчики VirtualBox внесли ряд исправлений, связанных с Linux Host:
VMM: исправлено аварийное завершение работы (синий экран) гостевых систем Windows 11 на архитектуре ARM после восстановления из сохранённого состояния;
GUI: исправлены переводы на немецкий язык и традиционный китайский язык;
Storage: исправлено повреждение данных в разностных образах VDI, возникавшее после записи полных блоков нулей и повторного открытия образа;
Graphics: исправлено аварийное завершение процесса виртуальной машины, которое могло происходить на хостах Linux при включённом 3D-ускорении;
Linux Host: исправлена ​​сборка с учётом изменений API открытия файлов в RHEL 9.8;
Linux Host: исправлена ​​сборка для систем AMD, где недоступна функция FRED (функция доступна только для Intel KVM;
Linux Host: устранены проблемы при компиляции для ядра Linux версии 7.3;
Linux Host: обеспечено сохранение общей директории DKMS при удалении программы;
Linux Host and Guest: добавлена ​​поддержка ядра RHEL 10.3;
Linux Guest: исправлена ​​сборка для ядра Linux версии 6.12.103.
Готовые установочные пакеты VirtualBox 7.2.18 опубликованы командой Oracle для RHEL 8/9/10, Fedora 40/41/42/43/44, openSUSE 15.6/16.0, Ubuntu 22.04/24.04/25.04/25.10/26.04, Debian 11/12/13, macOS и Windows.
