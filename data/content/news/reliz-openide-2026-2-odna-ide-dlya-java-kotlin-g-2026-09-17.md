Обновили базовую платформу до версии 2026.2, расширили поддержку Java и Kotlin, улучшили работу с Git и обновили Java‑профилировщик .
Доработали редактор и подсказки в терминале, добавили проверки настроек Gradle и упростили переход к исходникам библиотек. Через Git worktrees теперь можно работать с несколькими ветками одновременно.
Если вы впервые слышите про OpenIDE , это среда разработки на базе IntelliJ Platform с поддержкой Java, Kotlin, Go, Python, PHP, JavaScript и TypeScript в одном дистрибутиве. Помимо работы с кодом, в ней есть собственные инструменты для баз данных и Docker.
В 2026.2 вошли и обновления наших плагинов: DB‑клиента и Docker .
В DB‑клиенте добавили форматирование SQL и поддержку Greenplum, улучшили автодополнение и работу с пакетами Oracle. Несколько выделенных запросов теперь можно выполнить одним Ctrl+Enter , а в таблицах результатов появилась подсветка JSON. Если ещё не пробовали наш клиент, в отдельной статье показали, как подключиться к базе, написать запрос, посмотреть EXPLAIN и выгрузить данные.
В обновлённом Docker‑плагине сервисы из Compose‑файлов, подключённых через include , видны в общем дереве. Добавили навигацию по Docker‑описаниям через Structure и действие down with volumes — чтобы останавливать окружение и удалять его тома за один раз.
