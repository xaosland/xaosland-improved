Новые клиенты AWS теперь могут зарегистрироваться, используя учетную запись Google, GitHub или Apple, начать со 100 долларов США в виде кредитов уровня бесплатного пользования и создавать внутри «проекта», где AWS и агенты кодирования автоматически настраивают разрешения. Платные проекты получают ежемесячный лимит расходов, начиная с 20 долларов США, и проект, достигший этого лимита, останавливается, а не требует дополнительных расходов. Владельцы, которым позже понадобятся несколько регионов или централизованное управление, могут включить полную версию AWS… Подробнее → Сообщение Новая регистрация AWS дает ограничения на расходы учетных записей, приглашения по электронной почте и разрешения, установленные агентами, впервые появились в Help Net Security.
Новым клиентам AWS не нужно настраивать среду перед созданием чего-либо. Регистрация работает с существующим идентификатором Google, GitHub или Apple, и большинству новых клиентов не нужно вводить данные кредитной карты. Каждая учетная запись представляет собой проект: одна учетная запись AWS плюс настройки для ее совместного использования. AWS создает эту структуру при регистрации и добавляет элементы управления безопасностью, которые не указаны.
Мика Уолтер, старший архитектор решений в AWS, попробовал этот процесс, войдя в свою учетную запись Google, и его проект был готов за считанные секунды. На первом экране ему был предоставлен блок текста для его агента кодирования. Уолтер вставил его. Через несколько секунд агент вошел в систему с установленным интерфейсом командной строки AWS и набором инструментов агента для AWS, а также файлом CLAUDE.md с инструкциями по установке в его проекте.
