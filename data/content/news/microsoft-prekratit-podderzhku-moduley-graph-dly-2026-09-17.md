Microsoft объявила о прекращении поддержки модулей Graph для PowerShell 5.x и порекомендовала пользователям перейти на новую версию. В 2025 году компания сообщила о планах по выводу из эксплуатации некоторых компонентов Graph.
Microsoft Graph — это платформа для разработчиков, позволяющая приложениям, пользователям и служебным программам получать доступ к корпоративным данным и аналитической информации из облачных служб Microsoft 365 через единую конечную точку REST API.
В Microsoft отмечают, что PowerShell 7.x — это самая современная версия платформы, включающая множество внутренних улучшений, которые упрощают обслуживание и внедрение новых функций Graph. В связи с этим компания объявила о 12-месячном переходном периоде перед прекращением поддержки модулей Microsoft Graph PowerShell для PowerShell 5.x, переключая основные инженерные ресурсы на работу с PowerShell 7.x.
По сути, это означает, что модули Graph версии 2.x сохранят совместимость с PowerShell 5.x, и большинство из них продолжит работать в прежнем режиме. Однако новые функции будут ориентированы на PowerShell 7.x, а проблемы, характерные исключительно для PowerShell 5.x, больше не будут расследоваться или устраняться. Microsoft будет сворачивать поддержку этой платформы поэтапно, подчеркивая, что речь идет о «плановом переходе».
Компания планирует выпустить версию 3.0.0 модулей Graph PowerShell. Хотя существующие модули версии 2.x должны продолжать работать в среде PowerShell 5.x в течение указанного 12-месячного периода, их новые версии выпускаться не будут. Модули версии 3.x предназначены исключительно для PowerShell 7.x и не предусматривают поддержки PowerShell 5.x.
