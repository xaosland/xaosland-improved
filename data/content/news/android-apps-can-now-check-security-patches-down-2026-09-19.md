Новые библиотеки состояния безопасности AndroidX предоставляют более детальный способ определить, насколько надежно исправлено устройство Android. Стабильные библиотеки Security State v1.1.0 и Security State Provider v1.0.0 позволяют разработчикам проверять состояние безопасности отдельных компонентов устройства и определять, готовы ли обновления безопасности к загрузке и установке на конкретное устройство. Для производителей телефонов и разработчиков, создающих системы беспроводного обновления (OTA), библиотека androidx.security.state.provider предоставляет стандартный способ сообщить приложениям, когда для устройства доступно обновление.
«Поскольку Android эволюционировал, чтобы предоставлять быстрые, независимые обновления компонентов через модульные системы, такие как обновления системы Google Play, полагаться на одно свойство сборки SPL больше не является лучшим способом определить истинную степень безопасности устройства», — объяснили инженеры Google.
Вместо этого библиотеки состояния безопасности позволяют разработчикам проверять три уровня исправлений для отдельных частей устройства.
Уровень исправлений безопасности устройства (DSPL) показывает, что в данный момент установлено и работает на устройстве. Опубликованный уровень исправлений безопасности (PSPL) показывает последние исправления, которые компания официально опубликовала в Бюллетене по безопасности Android, а доступный уровень исправлений безопасности (ASPL) показывает, что доступно для загрузки и установки для данного конкретного устройства.
Проверки охватывают основную операционную систему Android, системные модули, обновляемые с помощью обновлений системы Google Play, и ядро ​​Linux. Уровни безопасности ядра используют номера версий, например 5.15.159 или 6.1.91, вместо ежемесячных дат исправлений безопасности.
