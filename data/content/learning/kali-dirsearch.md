<h2>Что это</h2>
<p>Этот пакет содержит инструмент командной строки, предназначенный для перебора каталогов и файлов на веб-серверах.</p>
<details><summary>Оригинал описания (EN)</summary>
<p>This package contains is a command-line tool designed to brute force directories and files in webservers.</p>
</details>
<h2>Пакеты и установка</h2>
<h3>dirsearch</h3>
<p><strong>Сканер веб-путей</strong><br>Установка: <code>sudo apt install dirsearch</code></p>
