<h2>Что это</h2>
<p>YARA — это инструмент, призванный помочь исследователям вредоносного ПО идентифицировать и классифицировать образцы вредоносного ПО. С помощью YARA можно создавать описания семейств вредоносных программ на основе текстовых или двоичных шаблонов, содержащихся в образцах этих семейств. Каждое описание состоит из набора строк и логического выражения, определяющего его логику.</p>
<details><summary>Оригинал описания (EN)</summary>
<p>YARA is a tool aimed at helping malware researchers to identify and classify malware samples. With YARA, it is possible to create descriptions of malware families based on textual or binary patterns contained in samples of those families. Each description consists of a set of strings and a Boolean expression which determines its logic.</p>
</details>
<h2>Пакеты и установка</h2>
<h3>libyara-dev</h3>
<p><strong>Библиотеки разработки и заголовки YARA</strong><br>Установка: <code>sudo apt install libyara-dev</code></p>
<h3>libyara10</h3>
<p><strong>Общая библиотека YARA</strong><br>Установка: <code>sudo apt install libyara10</code></p>
<h3>yara</h3>
<p><strong>Швейцарский нож для сопоставления шаблонов для исследователей вредоносного ПО</strong><br>Установка: <code>sudo apt install yara</code></p>
<h3>yara-doc</h3>
<p><strong>HTML-документация для YARA</strong><br>Установка: <code>sudo apt install yara-doc</code></p>
