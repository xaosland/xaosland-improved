<h2>Пакеты и установка</h2>
<h3>photorec</h3>
<p><strong>Инструмент восстановления файлов</strong><br>Установка: <code>sudo apt install photorec</code></p>
<h3>qphotorec</h3>
<p><strong>Графический интерфейс инструмента восстановления файлов PhotoRec.</strong><br>Установка: <code>sudo apt install qphotorec</code></p>
<h3>testdisk</h3>
<p><strong>Сканер разделов и инструмент восстановления диска</strong><br>Установка: <code>sudo apt install testdisk</code></p>
