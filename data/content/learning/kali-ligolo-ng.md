<h2>Что это</h2>
<p>Ligolo-ng — это простой, легкий и быстрый инструмент, который позволяет пентестерам устанавливать туннели из обратного соединения TCP/TLS с использованием интерфейса Tun (без необходимости использования SOCKS).</p>
<details><summary>Оригинал описания (EN)</summary>
<p>Ligolo-ng is a simple, lightweight and fast tool that allows pentesters to establish tunnels from a reverse TCP/TLS connection using a tun interface (without the need of SOCKS).</p>
</details>
<h2>Пакеты и установка</h2>
<h3>ligolo-ng</h3>
<p><strong>Усовершенствованный, но простой инструмент туннелирования/поворота, использующий интерфейс TUN.</strong><br>Установка: <code>sudo apt install ligolo-ng</code></p>
