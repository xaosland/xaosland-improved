<h2>Что это</h2>
<p>NetExec (AKA nxc) — это инструмент эксплуатации сетевых служб, который помогает автоматизировать оценку безопасности крупных сетей.</p>
<details><summary>Оригинал описания (EN)</summary>
<p>NetExec (AKA nxc) is a network service exploitation tool that helps automate assessing the security of large networks.</p>
</details>
<h2>Пакеты и установка</h2>
<h3>netexec</h3>
<p><strong>Инструмент сетевого выполнения</strong><br>Установка: <code>sudo apt install netexec</code></p>
