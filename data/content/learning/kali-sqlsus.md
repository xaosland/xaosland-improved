<h2>Что это</h2>
<p>sqlsus — это инструмент внедрения и контроля MySQL с открытым исходным кодом, написанный на Perl. Через интерфейс командной строки вы можете получить структуру базы данных, внедрить свои собственные SQL-запросы (даже сложные), загружать файлы с веб-сервера, сканировать веб-сайт в поисках доступных для записи каталогов, загружать и контролировать бэкдор, клонировать базы данных и многое другое&mldr; Когда это необходимо, sqlsus будет имитировать вывод консоли MySQL.</p>
<details><summary>Оригинал описания (EN)</summary>
<p>sqlsus is an open source MySQL injection and takeover tool, written in perl. Via a command line interface, you can retrieve the database(s) structure, inject your own SQL queries (even complex ones), download files from the web server, crawl the website for writable directories, upload and control a backdoor, clone the database(s), and much more&mldr; Whenever relevant, sqlsus will mimic a MySQL console output.</p>
</details>
