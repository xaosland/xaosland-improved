<h2>Что это</h2>
<p>Этот пакет содержит OWASP Maryam, модульную/дополнительную платформу с открытым исходным кодом, основанную на OSINT и сборе данных. Maryam написана на языке программирования Python и создана для предоставления мощной среды для сбора данных из открытых источников и поисковых систем, а также быстрого и тщательного сбора данных.</p>
<details><summary>Оригинал описания (EN)</summary>
<p>This package contains the OWASP Maryam, a modular/optional open source framework based on OSINT and data gathering. Maryam is written in Python programming language and it’s designed to provide a powerful environment to harvest data from open sources and search engines and collect data quickly and thoroughly.</p>
</details>
