<h2>Что это</h2>
<p>Этот пакет содержит быстрый туннель TCP/UDP, передаваемый по HTTP и защищенный через SSH. Один исполняемый файл, включающий как клиент, так и сервер. Chisel в основном полезен для прохождения через брандмауэры, хотя его также можно использовать для обеспечения безопасной конечной точки в вашей сети.</p>
<details><summary>Оригинал описания (EN)</summary>
<p>This package contains a fast TCP/UDP tunnel, transported over HTTP, secured via SSH. Single executable including both client and server. Chisel is mainly useful for passing through firewalls, though it can also be used to provide a secure endpoint into your network.</p>
</details>
