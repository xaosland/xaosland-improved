<h2>Что это</h2>
<p>Браузер Autopsy Forensic Browser — это графический интерфейс для инструментов цифрового судебно-медицинского анализа командной строки в The Sleuth Kit. Вместе The Sleuth Kit и Autopsy предоставляют многие из тех же функций, что и коммерческие инструменты цифровой криминалистики для анализа файловых систем Windows и UNIX (NTFS, FAT, FFS, EXT2FS и EXT3FS).</p>
<details><summary>Оригинал описания (EN)</summary>
<p>The Autopsy Forensic Browser is a graphical interface to the command line digital forensic analysis tools in The Sleuth Kit. Together, The Sleuth Kit and Autopsy provide many of the same features as commercial digital forensics tools for the analysis of Windows and UNIX file systems (NTFS, FAT, FFS, EXT2FS, and EXT3FS).</p>
</details>

<h3>autopsy</h3>
<p><strong>Графический интерфейс для SleuthKit</strong><br>Установка: <code>sudo apt install autopsy</code></p>
