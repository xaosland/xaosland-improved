<h2>Что это</h2>
<p>airgeddon — это оболочка сторонних инструментов, управляемая меню, для аудита беспроводных сетей со множеством функций.</p>
<details><summary>Оригинал описания (EN)</summary>
<p>airgeddon is a menu driven 3rd party tools wrapper to audit wireless networks with many features.</p>
</details>
<h2>Пакеты и установка</h2>
<h3>airgeddon</h3>
<p><strong>Многофункциональный bash-скрипт для систем Linux для аудита беспроводных сетей.</strong><br>Установка: <code>sudo apt install airgeddon</code></p>
