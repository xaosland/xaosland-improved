<h2>Что это</h2>
<p>GoldenEye — это инструмент тестирования HTTP DoS. Этот инструмент можно использовать для проверки уязвимости сайта к атакам типа «отказ в обслуживании» (DoS). Можно открыть несколько параллельных подключений к URL-адресу, чтобы проверить, может ли веб-сервер быть скомпрометирован.</p>
<details><summary>Оригинал описания (EN)</summary>
<p>GoldenEye is a HTTP DoS Test Tool. This tool can be used to test if a site is susceptible to Deny of Service (DoS) attacks. Is possible to open several parallel connections against a URL to check if the web server can be compromised.</p>
</details>
