<h2>Что это</h2>
<p>Этот пакет содержит набор инструментов для фишинга с открытым исходным кодом, предназначенный для предприятий и тестеров на проникновение. Он предоставляет возможность быстро и легко настраивать и выполнять фишинговые операции, а также проводить обучение по вопросам безопасности.</p>
<details><summary>Оригинал описания (EN)</summary>
<p>This package contains an open-source phishing toolkit designed for businesses and penetration testers. It provides the ability to quickly and easily setup and execute phishing engagements and security awareness training.</p>
</details>
<h2>Пакеты и установка</h2>
<h3>gophish</h3>
<p><strong>Набор инструментов для фишинга с открытым исходным кодом</strong><br>Установка: <code>sudo apt install gophish</code></p>
