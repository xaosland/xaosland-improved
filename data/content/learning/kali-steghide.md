<h2>Что это</h2>
<p>Steghide — это программа стеганографии, которая скрывает биты файла данных в некоторых младших битах другого файла таким образом, что существование файла данных не видно и не может быть доказано.</p>
<details><summary>Оригинал описания (EN)</summary>
<p>Steghide is steganography program which hides bits of a data file in some of the least significant bits of another file in such a way that the existence of the data file is not visible and cannot be proven.</p>
</details>
<h2>Пакеты и установка</h2>
<h3>steghide</h3>
<p><strong>Инструмент для сокрытия стеганографии</strong><br>Установка: <code>sudo apt install steghide</code></p>
<h3>steghide-doc</h3>
<p><strong>Инструмент сокрытия стеганографии — файлы документации</strong><br>Установка: <code>sudo apt install steghide-doc</code></p>
