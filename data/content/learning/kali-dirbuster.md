<h2>Что это</h2>
<p>DirBuster — это многопоточное Java-приложение, предназначенное для перебора имен каталогов и файлов на веб-серверах/серверах приложений. Сейчас часто бывает так, что то, что выглядит как веб-сервер в состоянии установки по умолчанию, на самом деле не является, и внутри него спрятаны страницы и приложения. DirBuster пытается их найти.</p>
<details><summary>Оригинал описания (EN)</summary>
<p>DirBuster is a multi threaded java application designed to brute force directories and files names on web/application servers. Often is the case now of what looks like a web server in a state of default installation is actually not, and has pages and applications hidden within. DirBuster attempts to find these.</p>
</details>
<h2>Пакеты и установка</h2>
<h3>dirbuster</h3>
<p><strong>Перебор каталога веб-сервера</strong><br>Установка: <code>sudo apt install dirbuster</code></p>
