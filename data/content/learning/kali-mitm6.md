<h2>Что это</h2>
<p>mitm6 — это инструмент для пентестинга, который использует конфигурацию Windows по умолчанию для захвата DNS-сервера по умолчанию. Он делает это, отвечая на сообщения DHCPv6, предоставляя жертвам локальный IPv6-адрес и устанавливая хост злоумышленников в качестве DNS-сервера по умолчанию.</p>
<details><summary>Оригинал описания (EN)</summary>
<p>mitm6 is a pentesting tool that exploits the default configuration of Windows to take over the default DNS server. It does this by replying to DHCPv6 messages, providing victims with a link-local IPv6 address and setting the attackers host as default DNS server.</p>
</details>
