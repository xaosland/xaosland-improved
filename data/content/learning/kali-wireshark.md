<h2>Что это</h2>
<p>Wireshark — это сетевой «сниффер» — инструмент, который перехватывает и анализирует пакеты, передаваемые по сети. Wireshark может декодировать слишком много протоколов, чтобы перечислять их здесь.</p>
<details><summary>Оригинал описания (EN)</summary>
<p>Wireshark is a network &ldquo;sniffer&rdquo; - a tool that captures and analyzes packets off the wire. Wireshark can decode too many protocols to list here.</p>
</details>
<h2>Пакеты и установка</h2>
<h3>libwireshark-data</h3>
<p><strong>Библиотека анализа сетевых пакетов – файлы данных</strong><br>Установка: <code>sudo apt install libwireshark-data</code></p>
<h3>libwireshark-dev</h3>
<p><strong>Библиотека анализа сетевых пакетов – файлы разработки</strong><br>Установка: <code>sudo apt install libwireshark-dev</code></p>
<h3>libwireshark19</h3>
<p><strong>Библиотека анализа сетевых пакетов – общая библиотека</strong><br>Установка: <code>sudo apt install libwireshark19</code></p>
<h3>libwiretap-dev</h3>
<p><strong>Библиотека захвата сетевых пакетов – файлы разработки</strong><br>Установка: <code>sudo apt install libwiretap-dev</code></p>
<h3>libwiretap16</h3>
<p><strong>Библиотека захвата сетевых пакетов – общая библиотека</strong><br>Установка: <code>sudo apt install libwiretap16</code></p>
<h3>libwsutil-dev</h3>
<p><strong>Библиотека утилит анализа сетевых пакетов – файлы разработки</strong><br>Установка: <code>sudo apt install libwsutil-dev</code></p>
<h3>libwsutil17</h3>
<p><strong>Библиотека утилит анализа сетевых пакетов – общая библиотека</strong><br>Установка: <code>sudo apt install libwsutil17</code></p>
<h3>stratoshark</h3>
<p><strong>Анализатор системных вызовов и журналов — графический и консольный интерфейсы</strong><br>Установка: <code>sudo apt install stratoshark</code></p>
<h3>tshark</h3>
<p><strong>Анализатор сетевого трафика — консольная версия</strong><br>Установка: <code>sudo apt install tshark</code></p>
<h3>wireshark</h3>
<p><strong>Анализатор сетевого трафика — графический интерфейс</strong><br>Установка: <code>sudo apt install wireshark</code></p>
<h3>wireshark-common</h3>
<p><strong>Анализатор сетевого трафика — общие файлы</strong><br>Установка: <code>sudo apt install wireshark-common</code></p>
<h3>wireshark-dev</h3>
<p><strong>Анализатор сетевого трафика — инструменты разработки</strong><br>Установка: <code>sudo apt install wireshark-dev</code></p>
<h3>wireshark-doc</h3>
<p><strong>Анализатор сетевого трафика — документация</strong><br>Установка: <code>sudo apt install wireshark-doc</code></p>
