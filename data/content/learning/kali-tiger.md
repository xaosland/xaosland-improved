<h2>Что это</h2>
<p>TIGER, или «тигровые» сценарии, представляет собой набор инструментов (скрипты оболочки Bourne и программы C), которые используются для выполнения аудита безопасности различных компонентов операционной системы. Инструменты можно запускать одновременно для создания отчета об аудите системы и для обнаружения элементов, которые можно исправить при усилении ее защиты.</p>
<details><summary>Оригинал описания (EN)</summary>
<p>TIGER, or the &rsquo;tiger&rsquo; scripts, is a set of tools (Bourne shell scripts and C programs) which are used to perform a security audit of different operating systems components. The tools can be both run all at once to generate an audit report of the system and to detect elements that could be fixed when hardening it.</p>
</details>

<h3>tiger</h3>
