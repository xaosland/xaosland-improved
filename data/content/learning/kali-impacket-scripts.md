<h2>Что это</h2>
<p>Этот пакет содержит ссылки на полезные скрипты импакетов. Это отдельный пакет для хранения пакета impacket из Debian и полезных скриптов для Kali.</p>
<details><summary>Оригинал описания (EN)</summary>
<p>This package contains links to useful impacket scripts. It&rsquo;s a separate package to keep impacket package from Debian and have the useful scripts in the path for Kali.</p>
</details>
<h2>Пакеты и установка</h2>
<h3>impacket-scripts</h3>
<p><strong>Ссылки на полезные примеры скриптов импакетов</strong><br>Установка: <code>sudo apt install impacket-scripts</code></p>
