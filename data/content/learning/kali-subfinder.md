<h2>Что это</h2>
<p>Этот пакет содержит инструмент обнаружения субдоменов, который обнаруживает действительные субдомены для веб-сайтов с помощью пассивных онлайн-источников. Он имеет простую модульную архитектуру и оптимизирован по скорости. subfinder создан только для одной цели — пассивного перечисления поддоменов, и он делает это очень хорошо.</p>
<details><summary>Оригинал описания (EN)</summary>
<p>This package contains a subdomain discovery tool that discovers valid subdomains for websites by using passive online sources. It has a simple modular architecture and is optimized for speed. subfinder is built for doing one thing only - passive subdomain enumeration, and it does that very well.</p>
</details>
<h2>Пакеты и установка</h2>
<h3>subfinder</h3>
<p><strong>Инструмент обнаружения поддоменов</strong><br>Установка: <code>sudo apt install subfinder</code></p>
