<h2>Что это</h2>
<p>Этот пакет содержит кросс-платформенную платформу имплантации общего назначения, которая поддерживает C2 через Mutual-TLS, HTTP(S) и DNS. Имплантаты динамически компилируются с использованием уникальных сертификатов X.509, подписанных центром сертификации каждого экземпляра, который создается при первом запуске двоичного файла.</p>
<details><summary>Оригинал описания (EN)</summary>
<p>This package contains a general purpose cross-platform implant framework that supports C2 over Mutual-TLS, HTTP(S), and DNS. Implants are dynamically compiled with unique X.509 certificates signed by a per-instance certificate authority generated when you first run the binary.</p>
</details>
