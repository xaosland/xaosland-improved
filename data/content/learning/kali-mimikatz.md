<h2>Что это</h2>
<p>Mimikatz использует права администратора в Windows для отображения паролей вошедших в систему пользователей в виде открытого текста.</p>
<details><summary>Оригинал описания (EN)</summary>
<p>Mimikatz uses admin rights on Windows to display passwords of currently logged in users in plaintext.</p>
</details>
<h2>Пакеты и установка</h2>
<h3>mimikatz</h3>
<p><strong>Использует права администратора в Windows для отображения паролей в виде открытого текста.</strong><br>Установка: <code>sudo apt install mimikatz</code></p>
