<h2>Что это</h2>
<p>OWASP Zed Attack Proxy (ZAP) — это простой в использовании интегрированный инструмент тестирования на проникновение для поиска уязвимостей в веб-приложениях.</p>
<details><summary>Оригинал описания (EN)</summary>
<p>The OWASP Zed Attack Proxy (ZAP) is an easy to use integrated penetration testing tool for finding vulnerabilities in web applications.</p>
</details>
<h2>Пакеты и установка</h2>
<h3>zaproxy</h3>
<p><strong>Инструмент тестирования для поиска уязвимостей в веб-приложениях</strong><br>Установка: <code>sudo apt install zaproxy</code></p>
