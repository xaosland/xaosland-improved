<h2>Что это</h2>
<p>ffuf — это быстрый веб-фаззер, написанный на Go, который позволяет выполнять типичное обнаружение каталогов, обнаружение виртуальных хостов (без записей DNS), а также фаззинг параметров GET и POST.</p>
<details><summary>Оригинал описания (EN)</summary>
<p>ffuf is a fast web fuzzer written in Go that allows typical directory discovery, virtual host discovery (without DNS records) and GET and POST parameter fuzzing.</p>
</details>
<h2>Пакеты и установка</h2>
<h3>ffuf</h3>
<p><strong>Быстрый веб-фаззер, написанный на Go (программа)</strong><br>Установка: <code>sudo apt install ffuf</code></p>
