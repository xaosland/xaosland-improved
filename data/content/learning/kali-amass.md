<h2>Что это</h2>
<p>Этот пакет содержит инструмент, который поможет специалистам по информационной безопасности составить карту сетевых поверхностей атак и обнаружить внешние активы, используя методы сбора информации с открытым исходным кодом и методы активной разведки.</p>
<details><summary>Оригинал описания (EN)</summary>
<p>This package contains a tool to help information security professionals perform network mapping of attack surfaces and perform external asset discovery using open source information gathering and active reconnaissance techniques.</p>
</details>
<h2>Пакеты и установка</h2>
<h3>amass</h3>
<p><strong>Углубленное перечисление DNS и сопоставление сетей</strong><br>Установка: <code>sudo apt install amass</code></p>
