<h2>Обзор игровых сервисов: Steam, Epic, GOG</h2>
<p>Цифровая дистрибуция игр — основной способ покупки. Рассмотрим три крупнейшие платформы.</p>

<h3>Steam</h3>
<ul>
  <li><strong>Плюсы:</strong> огромный каталог, регулярные скидки, удобное сообщество, Workshop, поддержка Linux через Proton.</li>
  <li><strong>Минусы:</strong> DRM, некоторые региональные ограничения.</li>
</ul>

<h3>Epic Games Store</h3>
<ul>
  <li><strong>Плюсы:</strong> бесплатные игры каждую неделю, эксклюзивы, более низкие комиссии для разработчиков.</li>
  <li><strong>Минусы:</strong> меньший каталог, отсутствие некоторых функций.</li>
</ul>

<h3>GOG</h3>
<ul>
  <li><strong>Плюсы:</strong> отсутствие DRM, старые игры адаптированы для современных систем, офлайн-установщики.</li>
  <li><strong>Минусы:</strong> ограниченный выбор новинок, более высокие цены.</li>
</ul>

<h3>Что выбрать?</h3>
<p>Steam — универсальный выбор. Epic — для бесплатных игр и эксклюзивов. GOG — для классики и отсутствия DRM.</p>
