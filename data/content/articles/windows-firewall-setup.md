<h2>Настройка брандмауэра Windows для максимальной безопасности</h2>
<p>Встроенный брандмауэр Windows — мощный инструмент, который многие недооценивают. В этой статье я покажу, как настроить его для эффективной защиты.</p>

<h3>Базовые принципы</h3>
<p>Брандмауэр фильтрует входящий и исходящий трафик на основе правил. По умолчанию он разрешает большинство исходящих соединений, что не всегда безопасно.</p>

<h3>Создание правила для блокировки порта</h3>
<pre><code>netsh advfirewall firewall add rule name="Блокировка 445" dir=in action=block protocol=TCP localport=445</code></pre>

<h3>Разрешение программы через брандмауэр</h3>
<p>Если программа не может получить доступ к сети, проверьте правила входящих/исходящих соединений. В панели управления выберите «Брандмауэр Windows» → «Разрешить взаимодействие» и добавьте своё приложение.</p>

<h3>Настройка уведомлений</h3>
<p>Включите уведомления о блокировке подключений, чтобы видеть попытки несанкционированного доступа.</p>

<h3>Использование профилей (домен, частная, общественная)</h3>
<p>Назначайте разные правила для разных сетей. Домашняя сеть может быть более доверительной, чем общественная в кафе.</p>

<h3>Интеграция с антивирусом</h3>
<p>Многие антивирусы имеют свой брандмауэр. Отключите один из них, чтобы избежать конфликтов.</p>
