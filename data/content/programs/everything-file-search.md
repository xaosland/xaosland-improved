<h2>Поиск, который быстрее вас печатает</h2>
<p>Встроенный поиск Windows славится тем, что «думает». Everything от voidtools индексирует все NTFS-диски за секунды и выдаёт результаты по мере ввода — поиск по миллиону файлов занимает миллисекунды.</p>

<h3>Почему так быстро</h3>
<p>Everything не сканирует содержимое файлов — только таблицу имён NTFS (MFT), читая её напрямую. Индекс обновляется в реальном времени через журнал изменений USN: переименовали файл — он уже в индексе.</p>

<h3>Что умеет</h3>
<p>Фильтры по типу (документы, видео, exe), поиск по маскам и регулярным выражениям, сортировка по дате и размеру, закладки на частые запросы. Есть HTTP- и FTP-сервер — можно искать по файлам своего домашнего ПК с телефона.</p>

<h3>Для продвинутых</h3>
<p>Поддерживает сложные запросы: <code>ext:pdf;djvu size:&gt;10mb dm:lastweek</code> — все PDF и DjVu тяжелее 10 МБ за последнюю неделю. Клиент крошечный (пара мегабайт), версия portable не требует установки.</p>

<h3>Вердикт</h3>
<p>Бесплатный, быстрый, без рекламы. Программа-обязаловка для любого ПК с Windows. Официальный сайт — voidtools.com.</p>
