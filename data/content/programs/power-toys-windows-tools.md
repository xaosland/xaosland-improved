<h2>Официальные «фишки» от Microsoft</h2>
<p>PowerToys — открытый набор утилит от Microsoft для Windows 10/11. Ставится через Microsoft Store или winget, обновляется сам. Каждая утилита включается отдельно — набора можно собрать под себя.</p>

<h3>Что ставит на колени первый месяц</h3>
<p><strong>FancyZones</strong> — свои сетки для окон: Shift+перетаскивание и окно встаёт в точную зону. Мультиоконные раскладки на 2+ мониторах — как родные.<br>
<strong>PowerRename</strong> — массовое переименование с regex и предпросмотром.<br>
<strong>Text Extractor</strong> — достаёт текст прямо с картинки на экране (OCR на любом языке).<br>
<strong>Color Picker</strong> — пипетка по системному хоткею, HEX/RGB/HSL на выбор.</p>

<h3>Мелочи, которые незаметно экономят часы</h3>
<p><strong>PowerToys Run</strong> (Alt+Space) — лончер: приложения, файлы, калькулятор, поиск в интернете без отрыва от клавиатуры.<br>
<strong>Keyboard Manager</strong> — ремап клавиш и комбинаций без реестра.<br>
<strong>Awake</strong> — держит ПК от сна без правки схем электропитания.<br>
<strong>Mouse Utilities</strong> — двойной Ctrl подсвечивает потерявшийся курсор.</p>

<h3>Как начать</h3>
<p>Установите из Microsoft Store или командой <code>winget install Microsoft.PowerToys</code>. Сначала включите 3–4 утилиты из списка выше — остальные изучите по мере надобности, их там два десятка.</p>

<h3>Вердикт</h3>
<p>Бесплатно, официально, открыто. Если вы работаете в Windows ежедневно — это must-have первого дня.</p>
