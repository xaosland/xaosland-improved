## Автоновости (RSS-парсер)

`scripts/fetch-news.js` тянет новости из RSS-лент (Habr, OpenNET, Lenta.ru, 3DNews, IXBT),
фильтрует по ключевым словам и складывает их в категорию **Новости** (`/news/`).

Ручной запуск:

```bash
npm run fetch-news   # спарсить ленты
npm run news         # спарсить + пересобрать сайт
npm run deploy       # собрать на VPS и атомарно выкатить в dist
```

На VPS настроен cron: каждые 2 часа парсер собирает новости и деплоит сайт.
Логи: `/var/log/xaosland-news.log`. Состояние дедупликации: `data/news-state.json`.

Переменные окружения: `NEWS_MAX_HOURS` (максимальный возраст новости, по умолчанию 48),
`NEWS_MAX_PER_RUN` (лимит статей за запуск, по умолчанию 12).

## Важное ограничение исходного набора

В переданных исходниках отсутствуют `data/content/**.md`, а также `about.html`, `contacts.html`, `privacy.html`. Поэтому сборка создаёт статьи с предупреждением об отсутствии Markdown-контента, а статические страницы будут сгенерированы автоматически после добавления соответствующих исходных файлов.

Установка зависимостей:

```bash
npm install
```

Сборка:

```bash
npm run build
```

Локальный запуск:

```bash
npm start
```
